# SuperTools — 365+ Pure Web Developer & Everyday Utilities

> **Zero backend. 100% Client-Side. Privacy-first Swiss Army Knife for developers, designers, and creators.**

SuperTools is a massive, unified web utility platform featuring **372 client-side tools** across 12 categories. All processing, calculations, conversions, cryptographic operations, file parsing, and image transformations execute strictly in the client's browser memory.

---

## 🚀 Key Highlights

- **365+ Utilities Built-In**: Comprehensive suite spanning developer utilities, cryptographic algorithms, math engines, financial planners, unit conversions, design utilities, and quick reference cheatsheets.
- **100% Client-Side Execution**: No data ever leaves your computer. No backend servers, no external tracking, no telemetry.
- **Fast Search (⌘K / Ctrl+K)**: Instant fuzzy lookup with arrow-key navigation and keyboard shortcuts.
- **Dark & Light Mode**: Seamless theme toggle with system preference detection and localStorage persistence.
- **Favorites & Recents**: One-click bookmarking of frequent tools and quick history access.
- **Offline Capable & Mobile Responsive**: Designed with responsive layouts and accessible controls.

## 🛠️ Technology Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS with custom dark mode theme
- **Icons**: Lucide React
- **Bundler & Dev Server**: Vite 6
- **Libraries**:
  - `crypto-js` for hashing & AES cryptographic operations
  - `qrcode` for QR code vector rendering
  - `jsqr` for client-side QR barcode image scanning
  - `diff` for text diff comparison
  - `papaparse` for CSV parsing
  - `js-yaml` for YAML parsing
  - `canvas-confetti` for celebratory animations

## 💻 Getting Started Locally

```bash
# Clone repository
git clone https://github.com/codero-sus/SuperTools.git
cd SuperTools

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🛡️ Privacy Guarantee

All computations, hashing, encryption, transformations, and file operations happen **100% inside your browser**.
- **No data is sent over the network.**
- **No logs, tracking, or telemetry.**
- **Safe for private keys, passwords, sensitive documents, and proprietary code.**
